# Login wallpaper

`login-wallpaper.jpg` is the existing rumahl `monstera.jpg` wallpaper, copied
from the pinned `assets/upstream/wallpapers` store. It is embedded in the auth
gateway so the first login has a background before the shell or user preferences
are available. Its license is `LicenseRef-Unsplash` (see the adjacent license).
